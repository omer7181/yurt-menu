# 🍽️ Yurt Yemek Menüsü

Kasım 2026 yurt yemekhanesi menüsünü mobil cihazlarda en sade, hızlı ve modernist tasarımla görüntüleyen web uygulaması.

---

## Özellikler

- **Günün Menüsü:**
  - **Kahvaltı**, **Ara Öğün** (hafta sonu) ve **Akşam Yemeği** ayrımı.
  - Sade ve modern kart yapısı (numaralandırılmış ürün listesi).
  - Yatay 7 günlük takvim şeridi ve hızlı gün geçişi (`Dün`, `Bugün`, `Yarın`).
  - Öğün filtresi (`Tümü`, `Kahvaltı`, `Akşam Yemeği`).
  - Sade WhatsApp paylaşım butonu.

- **Aylık Liste & Arama:**
  - Tüm ayın menüsü içinde hızlı arama (örn: *kruvasan, alinazik, pizza, menemen*).
  - Açılır-kapanır aylık takvim arşivi.

- **Güvenlik & Sadelik:**
  - Web arayüzü yalnızca görüntüleme odaklıdır
